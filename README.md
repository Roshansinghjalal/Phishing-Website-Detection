# Phishing-Website-Detection

A machine learning-based project to detect phishing websites using structured features and classification models such as Random Forest and XGBoost.

# 🛡️ Phishing Website Detection - Machine Learning Project

This project focuses on detecting phishing websites using various machine learning techniques. It involves exploratory data analysis, feature engineering, and classification modeling.

## 🎯 Objective

- Gain a deep understanding of phishing websites and their behavior.
- Analyze and visualize dataset features to uncover patterns and outliers.
- Preprocess and prepare the data for effective training.
- Train and evaluate classification models to predict phishing websites.

---

## 🧰 Tools & Technologies

- Python
- Jupyter Notebook
- pandas, numpy, matplotlib, seaborn
- scikit-learn

---

## 📊 Key Steps in the Project

1. **Literature Review** – Research on phishing techniques and online fraud.
2. **Data Understanding** – Study the feature set and distribution.
3. **EDA** – Use visualizations (histograms, pair plots, heatmaps) to explore relationships.
4. **Data Cleaning** – Handle missing values, outliers, and duplicates.
5. **Preprocessing** – Encode categorical variables and scale numerical ones.
6. **Model Training** – Apply classification models using an 80/20 train-test split.

---

- Accuracy scores and classification reports
- SHAP plots for model explanation
